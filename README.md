# 🍔 Quick Bites – Food Ordering System

A simple and interactive restaurant food ordering application built using **Python and Tkinter**. Quick Bites provides a user-friendly graphical interface for browsing food items, managing orders, calculating bills, and generating receipts.

## 📌 Project Overview

Quick Bites is a desktop-based food ordering system designed to simplify the restaurant ordering process. Customers can explore different food categories, add items to their cart, modify their orders, select a payment method, and view their final bill.

## ✨ Features

- 🍔 **Interactive Food Menu:** Browse Burgers, Pizza, Drinks, and Sides.
- 🛒 **Cart Management:** Add and remove food items from the cart.
- 🗑️ **Clear Cart:** Remove all selected items in one action.
- 💰 **Automatic Bill Calculation:** Calculate the total order amount dynamically.
- 👤 **Customer Details:** Enter the customer's name for the order.
- 💳 **Payment Method Selection:** Choose a payment method from the available options.
- 🧾 **Receipt Generation:** Display an order receipt with the order details.
- 🎨 **User-Friendly Interface:** Simple graphical interface built with Tkinter.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **GUI Framework:** Tkinter
- **Concepts:** Event Handling, GUI Development, Cart Management, and Billing Logic

## ⚙️ Installation and Setup

### Prerequisites

- Python 3 installed on your computer.
- Visual Studio Code or another Python-compatible editor (optional).

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your repository's actual URL.

### Step 2: Navigate to the Project Directory

```bash
cd Quick-Bites
```

If your repository has a different folder name, use that name instead.

### Step 3: Run the Application

```bash
python Restaurant.py
```

On Windows, if `python` is not recognized, try:

```bash
py Restaurant.py
```

## 🚀 How to Use

1. Launch the application.
2. Browse the available food categories.
3. Select food items and add them to the cart.
4. Remove individual items or clear the cart if needed.
5. Review the total bill.
6. Enter the customer name and select a payment method.
7. Generate and view the receipt.
